Every format you actually meet

Satsuma drives the tools Linux already trusts: ffmpeg, ImageMagick, poppler, pandoc and LibreOffice. If a tool is missing, its slices simply hide until you install it.

Hold Ctrl for the toolbox

Two dozen everyday edits, each one a single slice. Prompts are tiny, prefilled and keyboard-first: Enter confirms.

  • Compress images, video, audio and PDFs
  • Resize by percent or longest side
  • Crop to 1:1, 16:9, 9:16 or your own ratio
  • Trim audio and video to the second
  • Split PDFs by pages, media into parts
  • Merge PDFs, images into a PDF, clips, tracks
  • Rotate and flip
  • Grayscale photos, videos and PDFs
  • Strip metadata before you share
  • Extract audio or mute a video
  • Speed up or slow down
  • Video to GIF with a trim
  • Normalize loudness
  • Fade in and out
  • Frame rate and frame export
  • Encrypt and decrypt PDFs
  • Zip and tar.gz anything
  • Alt wheel: copy, move, trash, show in folder, float, send

Your files never leave the room

There is no server. Satsuma has no network code at all: every conversion runs on your CPU with open source tools you can inspect. Results are written next to the original, never over it, and half-finished files never appear: output is written to a hidden temp file and renamed only when complete.

  • No uploads, no telemetry, no account
  • Works on a plane
  • Never overwrites: photo 2.jpg
  • Cancel any time with Esc

Install

Ubuntu and Debian

Grab the package from the latest release, then:

sudo apt install ./satsuma_*_all.deb
Download .deb

Any distro

Installs into ~/.local. Run it with sudo to pull in the tools too.

curl -fsSL https://raw.githubusercontent.com/anmolxlight/satsuma/main/install.sh | bash

Then right-click any file in Files, Nemo, Dolphin or Thunar and choose Satsuma…, or bind satsuma --popup to a key.
